_Last updated: 2026-03-11_

## Module
- Name: Pmoves-Health-wger
- Path: Pmoves-Health-wger/

## Purpose in PMOVES.AI
- Health and fitness tracking service providing workout logging, exercise database,
  nutrition tracking, and body measurement history. Acts as the primary health data
  source for the PMOVES ecosystem, synced to Supabase and NATS event streams via n8n.

## PMOVES Overlay Surface
- pmoves-integrations/ overlay path: `pmoves/integrations/health-wger/`
- Compose/profile wiring: `pmoves/compose/docker-compose.wger.yml` (profile: `wger`)
- Env/secret inputs: `WGER_API_TOKEN` (auto-generated by `brand_defaults.py`),
  `WGER_BRAND_*` vars for site branding, database credentials in compose env
- Auth/JWT requirements: Django session auth for web UI; REST API uses token auth
  (`WGER_API_TOKEN` header: `Authorization: Token <token>`)

## Contracts and Topics
- NATS subjects:
  - `health.metrics.updated.v1` — Health domain summary and metrics updates
  - `health.workouts.synced.v1` — Workout data synced from Wger to Supabase
  - `health.weekly.summary.v1` — Weekly health CGP summary generated
  - `health.anomaly.detected.v1` — Health anomaly detected (triggers research)
- Supabase schema/tables touched: `pmoves_core.health_workouts`, `pmoves_core.health_measurements`
- MCP endpoints/skills: None (data access via REST API + n8n workflows)

## Boot Order and Health
- Bring-up dependency order: PostgreSQL (wger-db) -> Wger app -> n8n (for sync workflows)
- Health endpoints: `http://localhost:8000/api/v2/version` (REST API version check)
- Smoke targets: `make smoke-wger` (exercises API version endpoint + brand defaults)

## Hardening Notes
- Image pinning: `ghcr.io/cataclysm-studios-inc/pmoves-health-wger:pmoves-latest`
- Secrets source: `brand_defaults.py` auto-generates `WGER_API_TOKEN`;
  database passwords via compose env (override defaults before production)
- Network/security policy: Internal Docker network; admin password defaults to
  `adminadmin` on fresh bootstrap — rotate via Django management commands or UI
- **CRITICAL**: Change `adminadmin` default password on first bootstrap via
  `python manage.py changepassword admin` or the web UI. Consider adding
  `WGER_ADMIN_PASSWORD` to `brand_defaults.py` for auto-generation

## Mobile Applications
- **Android**: Official Wger Flutter app available on F-Droid and Google Play.
  Connects to self-hosted instance via REST API at `http://<host>:8000/api/v2/`.
- **iOS**: Official Wger Flutter app available on App Store. Same REST API connection.
- **Configuration**: Set the server URL in the app to your PMOVES Wger instance
  (e.g., `https://8000.localhost` via Pinokio HTTPS proxy or Tailscale URL).
  Authenticate with the same credentials used for the web UI.
